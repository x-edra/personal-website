# Tu carpeta de assets

Guarda aquí tus propios GIF, memes, fondos, botones pixelados, iconos e imágenes.

- `gifs/`: animaciones
- `memes/`: memes e imágenes
- `buttons/`: botones tipo 88×31
- `backgrounds/`: fondos y texturas

Desde Markdown puedes insertar, por ejemplo: `![mi gif](../assets/gifs/mi-gif.gif)` si el archivo Markdown está dentro de `docs/`. Las rutas relativas de HTML embebido se resuelven desde la página publicada, así que comprueba la ruta al desplegar.
