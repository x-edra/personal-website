# El protocolo central: IP

## Introducción

Los estándares modernos que rigen la conectividad global de los sistemas computacionales se basa principalmente en unas pocas ideas centrales. Una de ellas, dada por el Internet Protocol, es que todo dispositivo a conectarse a una red debe tener asociada una dirección de red. 

Esta dirección es relevante pues, dota de una capacidad de trazabilidad sobre los paquetes de datos (origen y destino), con la cuál la infraestructura de red es capaz de enviar y devolver peticiones.
